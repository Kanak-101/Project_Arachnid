Data ingestion layer
All ROS2 topics subscribed by a FastAPI bridge on the operator laptop. Topics: /camera/image_raw, /scan, /gas_sensors, /environmental, /imu/data, /flow_rate. Timestamped and stored in SQLite per inspection run.

Computer vision — YOLOv8 defect detection
Fine-tuned YOLOv8n (CODEBRIM + custom pipe dataset). Detects: cracks, root intrusions, joint offsets, sediment, corrosion. Each detection paired with SLAM pose → GPS-tagged coordinate. Runs ~15fps on RPi 5.

Sensor fusion — fault evidence aggregator
Python rules engine correlates sensor readings with visual detections. Rules: if (moisture_high AND ultrasonic_deform AND camera_crack) → structural_crack. if (flow_drop AND rgb_brown AND pm25_spike) → sediment_blockage. Gas readings correlated spatially with fault locations.

Aggregated fault evidence structured into JSON context → Claude API (claude-sonnet-4-6). System prompt: act as WRC-MSCC5 certified pipeline condition assessment engineer. Outputs: fault classification, failure risk timeline, root cause analysis, prioritised remediation recommendations with cost estimates.
