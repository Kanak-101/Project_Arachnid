Each bar is how often that joint hit its speed or range limit. A tall bar on one leg usually means that servo needs a lower max speed, a wider range, or a re-calibration.

Calibration walk-through

  1. Prop the robot so the legs hang free. Press Arm servos.
  2. Pick a leg on the map. Enable one servo, then jog it slowly with the buttons.
  3. Move the joint to the calibration pose (coxa straight out, femur level, tibia vertical) and press Set centre.
  4. Jog toward each end of travel. Press Set low / Set high a little before the horn hits the frame.
  5. Check the direction against the map. If the drawn leg moves the wrong way, press Invert.
  6. Jog to an angle you can measure, type it in, press Calibrate scale. Then run Sweep test.
  7. Press Save config.
